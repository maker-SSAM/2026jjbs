⌂ 메인으로 ◀ 레이저커터 슬라이드

2. 레이저커터 · 기기작동 매뉴얼

처음이어도 혼자 켜고, 결과물 하나를 만들고, 정리까지 할 수 있게 순서대로 적었어요.

모든 기기 공통

  • 처음 쓰기 전에 아래 안전 수칙부터 읽어요.
  • 기기가 작동하는 동안 자리를 비우지 않아요. (특히 레이저커터)
  • 이상한 소리·냄새·연기가 나면 바로 멈추고 담당 선생님께 알려요.
  • 고장 난 것 같으면 억지로 고치지 말고 "사용 중지" 표시를 붙여 두고 알려요.
  • 다 쓰면 전원 끄기 · 부스러기 치우기 · 재료 제자리까지가 사용이에요.

레이저커터 데이비드레이저 DV-7045 · 프로그램: RDWorks

⚠️ 안전 — 꼭 지켜요
  • 작동하는 동안 절대 자리를 비우지 않아요. 불이 붙을 수 있어요. 소화기 위치를 먼저 확인해요.
  • 냉각기와 배기팬을 켠 뒤에 레이저를 써요. 냉각 없이 쓰면 레이저관이 망가져요.
  • 작동 중에는 뚜껑을 열지 않아요. 레이저 빛을 직접 보지 않아요.
  • PVC·비닐·인조가죽은 절대 안 돼요(유독가스). 금속·거울처럼 빛을 반사하는 것도 안 돼요.
  • 쓸 수 있는 재료: 합판, MDF, 아크릴, 종이, 펠트.

켜는 순서

  1. 냉각기(칠러) 켜기 → 배기팬 켜기 → 레이저 본체 켜기 → 컴퓨터에서 RDWorks 열기

RDWorks에서 알아 둘 것

  • 속도·파워는 그림이 아니라 레이어(색)에 붙어요. 색마다 한 줄씩 값을 정해요.
  • 작업모드 컷 = 선을 따라 잘라요(약하게 하면 선 새기기). 스캔 = 닫힌 선의 안쪽을 채워 새겨요. 바깥부터 한 겹씩 번갈아 칠해서 테두리 띠·글자는 칠해지고 글자 속 구멍은 비어요.
  • 작업 화면에서는 스캔도 선으로만 보여요. 칠해지는 모양은 미리보기로 확인해요.
  • 파일: DXF = 그림과 색만(값 없음) · .rld = RDWorks 원본(그림 + 값) · .rd = 기계용 UFile(USB로 실행, 저장할 때 값 한 벌만 담김).

작업 순서

  1. 파일 가져오기: RDWorks에서 파일 → 가져오기(Ctrl+I)로 DXF를 열어요. 크기(mm)가 맞는지 봐요. 처음이면 연수자료의 이름표 만들기로 받아요. 이름표 DXF는 빨강(자르기)·검정(새기기) 레이어로 나뉘어 열려요. 여러 명 파일은 차례로 가져와 한 판에 늘어놓아요.
  2. 레이어 값 넣기: 오른쪽 레이어 목록에서 줄을 더블클릭 → 설정 창에서 작업모드(검정 = 스캔 · 빨강 = 컷), 속도, 파워를 고치고 확인. 옆 칸에 숫자를 치기만 하면 안 들어갈 때가 있어요. 최소·최대 파워는 같은 값으로 넣어요.
  3. 순서 정하기: 목록 위쪽부터 작업해요. 스캔을 먼저, 컷을 맨 마지막에 두어요(먼저 자르면 판이 움직여 어긋나요). 안쪽 구멍도 바깥 테두리보다 먼저 잘라야 해요.
  4. 미리보기: 스캔이 칠해지는지, 글자 속 구멍이 비는지 확인해요. 일부만 할 때는 그것만 골라 「선택 그래픽 출력」을 켜요.
  5. 저장: 파일 → 저장으로 .rld를 남겨요(그림 + 값). 값만 바꾸면 '저장'이 꺼져 있을 수 있으니 그때는 다른 이름으로 저장.
  6. 기계로 보내기: 다운로드(Download)로 바로 보내거나, 「UFile로저장」으로 .rd를 만들어 USB로 옮겨요. 기기 화면에서 파일을 골라요. 값을 바꿨으면 .rd를 다시 만들어요.
  7. 재료 놓기: 재료를 작업대에 평평하게 놓아요. 휘어 있으면 누름쇠로 눌러요.
  8. 초점 맞추기: 초점 자(블록)로 레이저 헤드와 재료 사이 높이를 맞춰요.
  9. 시작 자리 정하기: 방향키로 헤드를 재료의 시작 위치로 옮기고 Origin(원점)을 눌러요. RDWorks 시작위치가 '현 위치'면 헤드가 있는 자리가 기준이에요.
  10. 범위 확인: 「영역 보기」(Frame)를 눌러 헤드가 그리는 범위가 재료 안에 들어오는지, 기계와 연결이 되는지 봐요.
  11. 시작: 뚜껑을 닫고 Start. 끝날 때까지 지켜봐요.
  12. 꺼내기: 끝나고 연기가 빠질 때까지 잠깐 기다린 뒤 뚜껑을 열어요.

끄는 순서

  1. 레이저 본체 끄기 → 배기팬 끄기 → 냉각기 끄기 (켤 때의 반대)

설정값 예시 3mm 합판

작업속도파워(출력)
새기기(Scan)200~300 mm/s15~25%
자르기(Cut)10~20 mm/s60~70%

기기·재료마다 다르니 자투리 재료로 먼저 시험하고, 잘 맞는 값을 기기 옆에 적어 두세요.

문제 해결

끝까지 안 잘려요

자르기 속도를 낮추거나 출력을 높여 다시 한 번 자르세요(재료를 움직이지 않은 채로). 계속 안 되면 초점이 맞는지 봐요.

글씨와 테두리가 어긋나요

자르기를 먼저 하면 조각이 움직여요. 새기기 → 자르기 순서로 바꿔요.

불꽃이 계속 커져요

바로 일시정지(Pause) 또는 정지. 불이 꺼지지 않으면 소화기를 쓰고 담당 선생님께 알려요. 다음에는 속도를 높이거나 출력을 낮춰요.

새기기가 칠해지지 않고 선으로만 나와요

그 색 레이어의 작업모드가 스캔인지 봐요. 스캔은 닫힌 선의 안쪽만 칠하니, 선이 끊겨 있으면 안 칠해져요. 미리보기로 확인해요.

값을 바꿨는데 그대로 작업돼요

레이어 줄을 더블클릭해 설정 창에서 고치고 확인을 눌렀는지 봐요. USB로 할 때는 값을 바꾼 뒤 .rd를 다시 저장해야 해요(.rd에는 저장할 때의 값만 담겨요).

가져왔더니 크기가 이상해요

가져오기 할 때 단위가 mm인지 봐요. 연습 파일은 mm 그대로 만들어져 있어요.
