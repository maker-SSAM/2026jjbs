3. 승화전사기 · 기기작동 매뉴얼

처음이어도 혼자 켜고, 결과물 하나를 만들고, 정리까지 할 수 있게 순서대로 적었어요.

모든 기기 공통

  • 처음 쓰기 전에 아래 안전 수칙부터 읽어요.
  • 기기가 작동하는 동안 자리를 비우지 않아요. (특히 레이저커터)
  • 이상한 소리·냄새·연기가 나면 바로 멈추고 담당 선생님께 알려요.
  • 고장 난 것 같으면 억지로 고치지 말고 "사용 중지" 표시를 붙여 두고 알려요.
  • 다 쓰면 전원 끄기 · 부스러기 치우기 · 재료 제자리까지가 사용이에요.

승화전사 머그컵 기쁨기업 5구 머그 프레스

⚠️ 안전
  • 열패드(컵을 감싸는 빨간 부분)는 165℃까지 올라가요. 안쪽에 손대지 않아요.
  • 다 된 컵은 매우 뜨거워요. 손잡이만 잡고 꺼내고, 전사지는 내열 장갑을 끼고 떼요.
  • 컵 높이·조임 조절은 기기가 차가울 때만 해요.

설정값 이미 맞춰져 있어요

예열 온도160℃ (320℉)
작업 온도165℃ (330℉)
작업 시간60초

바꿀 때만: MODE를 누를 때마다 예열 온도 → 작업 온도 → 작업 시간 → 저장 순서로 넘어가고, ◀ ▶로 값을 바꿔요.

준비물 꼭 필요한 것

승화 잉크 프린터열을 받으면 기체가 되는 승화 잉크를 넣은 잉크젯 프린터. 집에서 쓰는 일반 잉크로는 컵에 안 찍혀요. 다른 잉크를 섞으면 노즐이 막히니 승화 전용으로만 써요. (손으로 꾸밀 때는 승화전사 색연필)
승화 전사지잉크를 종이 겉에 붙잡아 두었다가 열을 받으면 컵 쪽으로 내보내는 종이. 인쇄한 면이 컵에 닿게 감아요.
내열 테이프전사 테이프라고도 해요. 높은 열에도 녹거나 끈적이지 않아요. 종이가 조금만 움직여도 그림이 겹쳐 흐려지니 꼼꼼히 붙여요.
승화 코팅 머그겉에 승화용 코팅이 된 머그. 코팅이 열을 받아 열려야 잉크가 들어가요. 흰 바탕이어야 색이 제대로 보여요.
내열 장갑다 된 컵과 전사지는 매우 뜨거워요.

꼭 알아 둘 것

  • 잉크와 머그가 일반 것이면 아예 안 찍혀요. 종이·테이프가 맞지 않으면 흐려지거나 번져요.
  • 찍히면 좌우가 뒤집혀요. 인쇄는 프린터의 좌우 반전을 켜고, 손으로 꾸밀 때는 글씨 대신 그림 위주로 해요.
  • 승화 잉크는 인쇄하거나 칠했을 때 흐리고 탁해 보여도 열을 받으면 진해져요. 색연필은 진하게 칠해요.
  • 화면(RGB)과 프린터(CMYK)는 색을 내는 방식이 달라서, 찍힌 색이 화면과 조금 다를 수 있어요.
  • 칸마다 전원이 따로라서 필요한 칸만 켜면 돼요. 5칸 모두 켜면 컵 5개를 한 번에 찍어요.

도안 만들기 프린터로 인쇄할 때

  1. 머그 재기: 줄자로 쓸 머그의 둘레와 높이를 재요. 도안 가로 = 둘레 − 2~3cm(손잡이 쪽 빈칸), 세로 = 높이 − 1cm(위아래 5mm씩 여유).
  2. 도안 틀 받기: 머그컵 도안 틀(PPTX)을 내려받아요. 점선 틀이 200×90mm(11oz 머그 기준)예요. 잰 값과 다르면 점선 틀 크기를 잰 값으로 바꿔요.
  3. 그림 넣기: 그림·글자를 점선 틀에 맞춰 넣어요. 바탕을 꽉 채우려면 틀보다 2mm쯤 크게. 양 끝이 손잡이 쪽, 가운데가 앞면이에요.
  4. 점선 틀 지우기: 인쇄 전에 점선 틀만 지워요(재단 표시는 남겨요).
  5. 실제 크기로 인쇄: 인쇄 창에서 실제 크기(100%)를 고르고 「용지에 맞게 크기 조정」은 꺼요. 새로 만들 때 PowerPoint의 'A4 용지' 크기는 27.5×19.05cm라 1:1이 아니에요. 도안 틀(A4 실제 크기)을 쓰면 돼요.
  6. 좌우 반전: 프린터 설정의 좌우 반전(미러·좌우대칭)을 켜요. PowerPoint에서 텍스트 상자를 대칭 뒤집기 해도 글자는 뒤집히지 않아요.
  7. 먼저 일반 종이로: 처음에는 일반 종이에 한 장 인쇄해 10cm 눈금을 자로 재고, 머그에 둘러 크기를 확인해요. 맞으면 승화 전사지에 인쇄해요.

학교 프린터가 엡손 승화 프린터(L8050 등)라면 승화나라 안내의 인쇄 기본 설정 예: 용지 종류 「Epson 사진 품질 잉크젯 전용지」, 「양방향 인쇄」 끄기, 좌우대칭은 필요할 때 켜기. 프린터·잉크마다 다르니 판매처 안내를 따라요.

사용 순서

  1. 전원 켜기: 앞쪽의 칸별 빨간 전원 스위치를 쓸 칸만 켜요. 예열 온도까지 올라가요.
  2. 전사지 준비: 예열되는 동안 위 「도안 만들기」대로 인쇄한 전사지를 재단 표시대로 잘라요. 손으로 꾸밀 때는 예시 도안이 있는 전사지의 빈 곳을 승화전사 색연필로 꾸며요.
  3. 컵에 감기: 그림 면이 컵 쪽으로 가게, 앞면 가운데가 손잡이 반대쪽에 오게 감아요. 이음매와 위아래를 내열 테이프로 붙여 들뜨지 않게 해요.
  4. 예열 완료: 예열 온도가 되면 '띠~ 띠~' 소리가 나요.
  5. 컵 넣기: 컵을 열패드 안에 넣고 손잡이가 바깥으로 나오게 한 뒤 레버를 닫아 꽉 조여요.
  6. 자동 시작: 레버만 닫으면 저절로 시작돼요. 차가운 컵 때문에 온도가 잠깐 떨어졌다가 165℃가 되면 60초를 세요.
  7. 꺼내기: 다시 '띠~ 띠~' 소리가 나면 레버를 풀고, 손잡이를 잡고 꺼내 내열 장갑을 끼고 바로 전사지를 떼요. 오래 붙여 두면 그림이 번져 흐려져요.
  8. 식히기·끄기: 컵은 식히는 자리에 서로 떨어뜨려 두어요. 뜨거운 컵끼리 붙어 있으면 옆 컵에 잉크가 옮아 붙어요. 선풍기 바람으로 식히면 좋고, 물에 담그지는 않아요(깨질 수 있어요). 다 쓰면 칸별 전원을 꺼요.

문제 해결

아예 안 찍히거나 문지르면 지워져요

머그가 승화 코팅 머그인지, 프린터 잉크가 승화 잉크인지 확인해요. 둘 중 하나라도 일반 것이면 안 돼요.

크기가 안 맞아요

인쇄가 「용지에 맞게」로 줄었을 수 있어요. 10cm 눈금을 자로 재 보고, 실제 크기(100%)로 다시 인쇄해요.

글자가 거꾸로 찍혔어요

프린터 설정의 좌우 반전(미러)을 켜고 인쇄해야 해요.

색이 흐려요

더 진하게 칠해요. 컵이 열패드에 꽉 닿지 않았을 수도 있어요 — 아래 "컵이 헐거워요"를 봐요.

그림이 번지거나 얼룩이 생겼어요

전사지가 컵에서 들떴거나, 끝나고 종이를 늦게 뗐을 때 생겨요. 테이프로 꼼꼼히 붙이고, 끝나면 바로 떼요. 꺼낸 뒤에는 컵끼리 떨어뜨려 두고 선풍기 바람으로 빨리 식혀요. 그래도 진한 색이 번지거나 타는 듯 붉게 나오면 온도·시간 설정 문제일 수 있으니 담당 선생님께 알려요(설정은 담당 선생님만 바꿔요).

프린터에서 줄이 생기거나 색이 빠져요

노즐이 막힌 거예요. 승화 잉크는 오래 쉬면 굳기 쉬워서 자주 인쇄하는 게 좋아요. 프린터의 노즐 검사를 해 보고, 헤드 청소 뒤 30분~1시간 쉬었다가 다시 검사해요. 엡손 승화 프린터는 「파워 클리닝」을 하지 말라는 안내가 있어요.

컵이 헐겁거나 위아래로 치우쳐요

기기가 차가울 때 조절해요. 컵 아래 받침을 돌려 컵이 패드 가운데 오게 하고, 레버 쪽 조절 나사를 돌려 컵이 패드에 꽉 닿게 해요.

참고: 승화나라(shnr.co.kr) 전사노하우·프린터관리법 게시판 내용을 요약해 이 기기에 맞게 다시 썼어요.
