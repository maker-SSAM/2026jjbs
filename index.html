무한상상실 기기 사용법

처음이어도 혼자 켜고, 결과물 하나를 만들고, 정리까지 할 수 있게 순서대로 적었어요.

3D프린터큐비콘 Style Plus · 5대 레이저커터데이비드 DV-7045 · 1대 승화전사 머그머그 프레스 5구 버튼제작기1대

모든 기기 공통

  • 처음 쓰기 전에 이 페이지의 안전 수칙부터 읽어요.
  • 기기가 작동하는 동안 자리를 비우지 않아요. (특히 레이저커터)
  • 이상한 소리·냄새·연기가 나면 바로 멈추고 담당 선생님께 알려요.
  • 고장 난 것 같으면 억지로 고치지 말고 "사용 중지" 표시를 붙여 두고 알려요.
  • 다 쓰면 전원 끄기 · 부스러기 치우기 · 재료 제자리까지가 사용이에요.

3D프린터 큐비콘 Style Plus (A15CR) · 슬라이서: 큐비크리에이터

⚠️ 안전
  • 노즐(실이 나오는 곳)과 바닥판은 매우 뜨거워요. 출력 중·직후에 손대지 않아요.
  • 출력 중에는 문을 열지 않아요. 움직이는 부품에 손이 끼일 수 있어요.
  • 출력물은 바닥판이 식은 뒤 떼요.

연습 파일
문구만 쓰면 이름 키링 STL이 나와요.

키링 만들기

사용 순서

  1. 전원 켜기: 프린터 전원을 켜고, 필라멘트(실)가 충분히 남았는지 확인해요.
  2. 파일 준비: 3D 모델 파일(STL)을 준비해요. 처음이면 키링 만들기로 받아요.
  3. 큐비크리에이터 열기: 프린터 기종이 Style Plus로 골라져 있는지 확인해요.
  4. 불러오기: STL을 끌어다 놓아요. 바닥에 평평하게 눕혀 있고 판 가운데 있는지 봐요.
  5. 설정: 처음에는 기본 설정 그대로 써요. 키링처럼 납작한 것은 지지대(서포트)가 필요 없어요.
  6. 슬라이싱: 슬라이싱 버튼을 누르고 예상 시간을 확인해요. 수업 시간 안에 끝나는지 꼭 봐요.
  7. 보내기: USB에 저장하거나 네트워크로 프린터에 보내요.
  8. 출력 시작: 프린터 화면에서 파일을 골라 시작해요.
  9. 첫 층 지켜보기: 처음 5분, 실이 바닥에 잘 붙는지 봐요. 안 붙으면 멈추고 아래 "문제 해결"을 봐요.
  10. 꺼내기·정리: 바닥판이 식으면 출력물을 떼고, 실 찌꺼기를 치워요.

필라멘트(실) 바꾸기

  1. 프린터 화면의 필라멘트 메뉴에서 빼기(언로드)를 골라요. 노즐이 데워지면 실이 풀려요.
  2. 실 끝을 비스듬히 잘라 새 실을 준비해요. 실 끝이 풀리지 않게 잡고 있어요.
  3. 넣기(로드)를 골라 새 실을 밀어 넣어요. 노즐에서 새 색이 나오면 끝이에요.

문제 해결

첫 층이 바닥에 안 붙어요

바닥판의 손자국·먼지를 닦고 다시 시작해요. 그래도 안 되면 바닥 수평 맞추기(레벨링)를 하거나, 큐비크리에이터에서 브림을 켜요.

실이 안 나와요 / 중간에 멈췄어요

실이 다 떨어졌는지, 엉켰는지 봐요. 실이 충분한데도 안 나오면 노즐이 막힌 것일 수 있어요 — 담당 선생님께 알려요.

출력물이 안 떨어져요

바닥판이 완전히 식을 때까지 기다려요. 억지로 떼면 바닥판이 상해요.

수업 팁: 학생 수만큼 출력하려면 작은 것 여러 개를 한 판에 모아 한 번에 뽑아요. 5대를 나눠 쓰면 시간이 줄어요.

레이저커터 데이비드레이저 DV-7045 · 프로그램: RDWorks

⚠️ 안전 — 꼭 지켜요
  • 작동하는 동안 절대 자리를 비우지 않아요. 불이 붙을 수 있어요. 소화기 위치를 먼저 확인해요.
  • 냉각기와 배기팬을 켠 뒤에 레이저를 써요. 냉각 없이 쓰면 레이저관이 망가져요.
  • 작동 중에는 뚜껑을 열지 않아요. 레이저 빛을 직접 보지 않아요.
  • PVC·비닐·인조가죽은 절대 안 돼요(유독가스). 금속·거울처럼 빛을 반사하는 것도 안 돼요.
  • 쓸 수 있는 재료: 합판, MDF, 아크릴, 종이, 펠트.

연습 파일
문구만 쓰면 책갈피·키링 DXF가 나와요. 여러 명을 한 판에 모아요.

파일 만들기

켜는 순서

  1. 냉각기(칠러) 켜기 → 배기팬 켜기 → 레이저 본체 켜기 → 컴퓨터에서 RDWorks 열기

작업 순서

  1. 파일 가져오기: RDWorks에서 파일 → 가져오기(Ctrl+I)로 DXF를 열어요. 크기(mm)가 맞는지 봐요.
  2. 레이어 정하기: 오른쪽 목록에서 색마다 더블클릭해 정해요.
    검정 = Scan(새기기) · 빨강 = Cut(자르기)
  3. 순서 정하기: 새기기를 먼저 하도록 검정 레이어를 위로 올려요. 안쪽 구멍도 바깥 테두리보다 먼저 잘라야 해요.
  4. 기기로 보내기: 다운로드(Download)로 기기에 보내요(또는 USB). 기기 화면에서 파일을 골라요.
  5. 재료 놓기: 재료를 작업대에 평평하게 놓아요. 휘어 있으면 누름쇠로 눌러요.
  6. 초점 맞추기: 초점 자(블록)로 레이저 헤드와 재료 사이 높이를 맞춰요.
  7. 원점 정하기: 방향키로 헤드를 재료의 시작 위치로 옮기고 Origin(원점)을 눌러요.
  8. 테두리 확인: Frame(테두리)을 눌러 헤드가 그리는 범위가 재료 안에 들어오는지 봐요.
  9. 시작: 뚜껑을 닫고 Start. 끝날 때까지 지켜봐요.
  10. 꺼내기: 끝나고 연기가 빠질 때까지 잠깐 기다린 뒤 뚜껑을 열어요.

끄는 순서

  1. 레이저 본체 끄기 → 배기팬 끄기 → 냉각기 끄기 (켤 때의 반대)

설정값 예시 3mm 합판

작업속도출력
새기기(Scan)200~300 mm/s15~25%
자르기(Cut)10~20 mm/s60~70%

기기·재료마다 다르니 자투리 재료로 먼저 시험하고, 잘 맞는 값을 기기 옆에 적어 두세요.

문제 해결

끝까지 안 잘려요

자르기 속도를 낮추거나 출력을 높여 다시 한 번 자르세요(재료를 움직이지 않은 채로). 계속 안 되면 초점이 맞는지 봐요.

글씨와 테두리가 어긋나요

자르기를 먼저 하면 조각이 움직여요. 새기기 → 자르기 순서로 바꿔요.

불꽃이 계속 커져요

바로 일시정지(Pause) 또는 정지. 불이 꺼지지 않으면 소화기를 쓰고 담당 선생님께 알려요. 다음에는 속도를 높이거나 출력을 낮춰요.

가져왔더니 크기가 이상해요

가져오기 할 때 단위가 mm인지 봐요. 연습 파일은 mm 그대로 만들어져 있어요.

승화전사 머그컵 기쁨기업 5구 머그 프레스

⚠️ 안전
  • 열패드(컵을 감싸는 빨간 부분)는 165℃까지 올라가요. 안쪽에 손대지 않아요.
  • 다 된 컵은 매우 뜨거워요. 손잡이만 잡고 꺼내고, 전사지는 내열 장갑을 끼고 떼요.
  • 컵 높이·조임 조절은 기기가 차가울 때만 해요.

설정값 이미 맞춰져 있어요

예열 온도160℃ (320℉)
작업 온도165℃ (330℉)
작업 시간60초

바꿀 때만: MODE를 누를 때마다 예열 온도 → 작업 온도 → 작업 시간 → 저장 순서로 넘어가고, ◀ ▶로 값을 바꿔요.

꼭 알아 둘 것

  • 승화 코팅된 머그에만 찍혀요. 일반 컵에는 안 돼요.
  • 찍히면 좌우가 뒤집혀요. 손으로 쓰는 글자는 거꾸로 써야 해서, 빈 곳은 그림 위주로 꾸며요.
  • 승화전사 색연필은 칠할 때 흐려 보여도 열을 받으면 진해져요. 진하게 칠해요.
  • 칸마다 전원이 따로라서 필요한 칸만 켜면 돼요. 5칸 모두 켜면 컵 5개를 한 번에 찍어요.

사용 순서

  1. 전원 켜기: 앞쪽의 칸별 빨간 전원 스위치를 쓸 칸만 켜요. 예열 온도까지 올라가요.
  2. 꾸미기: 예열되는 동안 예시 도안이 있는 전사지의 빈 곳을 승화전사 색연필로 꾸며요.
  3. 컵에 감기: 그림 면이 컵 쪽으로 가게 감고, 들뜨지 않게 내열 테이프로 붙여요.
  4. 예열 완료: 예열 온도가 되면 '띠~ 띠~' 소리가 나요.
  5. 컵 넣기: 컵을 열패드 안에 넣고 손잡이가 바깥으로 나오게 한 뒤 레버를 닫아 꽉 조여요.
  6. 자동 시작: 레버만 닫으면 저절로 시작돼요. 차가운 컵 때문에 온도가 잠깐 떨어졌다가 165℃가 되면 60초를 세요.
  7. 꺼내기: 다시 '띠~ 띠~' 소리가 나면 레버를 풀고, 손잡이를 잡고 꺼내 내열 장갑을 끼고 바로 전사지를 떼요. 오래 붙여 두면 그림이 번져 흐려져요.
  8. 식히기·끄기: 컵은 식히는 자리에 두고, 다 쓰면 칸별 전원을 꺼요.

문제 해결

색이 흐려요

더 진하게 칠해요. 컵이 열패드에 꽉 닿지 않았을 수도 있어요 — 아래 "컵이 헐거워요"를 봐요.

그림이 번지거나 얼룩이 생겼어요

전사지가 컵에서 들떴거나, 끝나고 종이를 늦게 뗐을 때 생겨요. 테이프로 꼼꼼히 붙이고, 끝나면 바로 떼요.

컵이 헐겁거나 위아래로 치우쳐요

기기가 차가울 때 조절해요. 컵 아래 받침을 돌려 컵이 패드 가운데 오게 하고, 레버 쪽 조절 나사를 돌려 컵이 패드에 꽉 닿게 해요.

버튼제작기

⚠️ 안전
  • 레버를 내릴 때 틀 위에 손을 두지 않아요. 손가락이 끼일 수 있어요.

준비물

색칠한 도안(원) · 원형 커터(또는 가위) · 금속 앞판 · 투명 필름 · 뒷판(핀)

사용 순서

  1. 도안 오리기: 우리 기계 크기에 맞는 원으로 오려요(원형 커터가 편해요).
  2. 앞판 틀: 금속 앞판(볼록한 면이 위) → 도안(그림이 위) → 필름 순서로 올려요.
  3. 첫 번째 누르기: 틀을 레버 아래로 돌리고 끝까지 꾹 눌렀다 올려요.
  4. 뒷판 틀: 반대쪽 틀에 뒷판을 핀이 아래로 가게 놓아요. 핀 방향이 그림의 위아래와 맞는지 확인해요.
  5. 두 번째 누르기: 틀을 돌려 다시 끝까지 꾹 누르면 완성이에요.

기계마다 순서가 조금 다를 수 있어요. 기계에 붙은 그림 설명이 있으면 그것을 따라요.

문제 해결

도안이 삐져나오거나 주름이 져요

원이 너무 크거나 작아요. 기계 크기에 맞는 도안을 쓰고, 가운데 맞춰 올려요.

뒷판이 안 붙어요

첫 번째 누르기를 끝까지 눌렀는지 확인하고, 뒷판 방향을 바꿔 다시 눌러요.
